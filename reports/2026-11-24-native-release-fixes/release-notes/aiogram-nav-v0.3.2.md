# aiogram-nav 0.3.2

Keep standalone navigation, optional Redis storage and optional Idle integration. Native JSON/state handling preserves callback ownership, leases, partial-render recovery and FSM coordination.

Python is the default. This SDK has no mandatory native dependency or native extra. Explicit Rust selection requires the independently installed `aiogram-nav-native==0.3.2` companion (ABI 1). Missing or incompatible companions fail before effects.

Standalone SDK wheels and source archives are verified separately. SDK and companion versions, tags, checksums and releases remain independent.

Draft release notes: publication requires successful final CI, exact-artifact qualification/manifests, publisher setup and a separate publishing instruction.
