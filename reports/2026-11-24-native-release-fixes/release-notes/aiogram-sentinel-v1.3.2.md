# aiogram-sentinel 1.3.2

Preserve per-handler rate/debounce policies, Redis behavior and error propagation while exposing an explicitly selected native rate/debounce core.

Python is the default. This SDK has no mandatory native dependency or native extra. Explicit Rust selection requires the independently installed `aiogram-sentinel-native==1.3.2` companion (ABI 1). Missing or incompatible companions fail before effects.

Standalone SDK wheels and source archives are verified separately. SDK and companion versions, tags, checksums and releases remain independent.

Exact artifacts and workload scope are recorded in the qualification report and SHA256SUMS.
