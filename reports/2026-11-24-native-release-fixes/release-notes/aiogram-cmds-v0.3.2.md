# aiogram-cmds 0.3.2

Use compiled immutable snapshots for native batch resolution. Live translators remain uncached. Resolved native fingerprint hashing borrows Python strings without changing canonical digests or caller-owned confirmations.

Python is the default. This SDK has no mandatory native dependency or native extra. Explicit Rust selection requires the independently installed `aiogram-cmds-native==0.3.2` companion (ABI 1). Missing or incompatible companions fail before effects.

Standalone SDK wheels and source archives are verified separately. SDK and companion versions, tags, checksums and releases remain independent.

Draft release notes: publication requires successful final CI, exact-artifact qualification/manifests, publisher setup and a separate publishing instruction.
