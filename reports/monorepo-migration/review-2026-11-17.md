## Findings and corrections

1. **Latest-main compatibility tests failed.** At starting commit
   `9950721a398243ddd05230400745f6982a40304b`, Nav and Idle CI failed while the other
   ten main workflows passed. aiogram's native command filter requests `GetChat` to
   resolve bot usernames; two recording test transports did not return `ChatFullInfo`.
   Supply valid bot chat identity responses in those test doubles, including the latest
   required gift settings. Keep the existing
   assertions rejecting foreign command mentions. Production library behavior is unchanged.
2. **Publish-job integrity depended only on the pre-upload verification.** All six existing
   releases have correct artifacts and successful publishing runs, but the job consuming
   the Actions artifact did not rehash it. Bind download to the producer's immutable
   artifact ID, include the reviewed checksum manifest in that handoff, then recheck
   both file hashes against the independently supplied manifest digest in the publish job.
   Prepare a clean `dist/` containing exactly the wheel and sdist; do not publish the
   checksum manifest. Keep the six filenames, tag guards, OIDC permissions and publishers.
   `tools/publish_handoff.py --write` maintains the shared inline step; its default mode
   checks all six workflows for drift.
3. **Archive validation missed unsafe member paths and types.** Reject traversal,
   absolute/Windows paths, links, special files, duplicate members, foreign sdist roots
   and ambiguous identity headers, even when file hashes match an approved manifest.
   All twelve real published artifacts pass the strengthened verifier unchanged.
4. **History metadata named temporary refs.** Five `history_ref` entries still pointed
   at local import prefixes. Replace them with the published immutable refs and explicitly
   include surviving Sentinel ancestry. Require matching source-head/ref mappings and
   verify all 100 advertised remote ref targets in CI; an available local object alone
   no longer proves a published ref remains preserved.
5. **Main automation coverage was incomplete.** Shared optimization tests ran only on
   matching changed paths, and docs required manual deployment. Run shared-tool coverage
   on every main push. Build/deploy docs automatically on main, preserve manual dispatch,
   and keep PR builds read-only. Concurrency prevents stale docs builds from winning.
   Make broken anchors and unrecognized documentation links strict build errors.
6. **Three removed workflow files remained registered as active.** Disable those orphaned
   Changelog/PR-management/old optimization registrations. Preserve their IDs and historical
   runs. The current shared changelog guard and optimization workflow remain active.

7. **The shared release verifier did not import on Python 3.10.** It used `tomllib`
   directly despite the workspace's Python floor. Add the conditional `tomli` fallback
   as a development-only dependency, and check workspace tooling on 3.10/3.12/3.14.
   The Python 3.10 documentation dependency set has incompatible highlighting plugins;
   keep strict documentation builds on their verified Python 3.12 toolchain. All three
   versions still run preservation, artifact and shared-tool checks. No SDK dependency range changes.
