# aiogram-sentinel-native 1.3.2

Independently installed optional Rust companion, paired exactly with `aiogram-sentinel==1.3.2` and ABI 1. It has no SDK or Redis dependency of its own. SDK Python operation remains the default.

Targets: CPython 3.10 stable ABI, exercised on regular CPython 3.10–3.14; Linux glibc/musl x86_64/aarch64, macOS x86_64/arm64 and Windows AMD64. Source builds use the retained Cargo.lock. PyPy and free-threaded CPython are not advertised native targets.

Publication requires the final exact-artifact readiness report and independent SHA256 manifest review. No tag, GitHub release or PyPI upload is created by preparation.
